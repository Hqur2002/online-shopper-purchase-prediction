# Online Shopper Purchase Prediction Using Machine Learning

## Project Overview
This project explores how machine learning can predict whether an online shopper will complete a purchase based on browsing behavior and session information.

## Technologies Used
- Python
- Pandas
- Scikit-learn
- Jupyter Notebook / Google Colab
- Logistic Regression

## Machine Learning Workflow
1. Load and explore the Online Shoppers Purchasing Intention dataset.
2. Prepare the data for machine learning.
3. Split the dataset into training and testing sets.
4. Train a logistic regression classification model.
5. Evaluate model performance using accuracy, precision, recall, and a confusion matrix.

## Project Goals
- Apply machine learning to a real-world classification problem.
- Understand how browsing behavior relates to purchasing decisions.
- Evaluate predictive model performance.
- Gain practical experience with Python-based machine learning tools.

## Running the Project
1. Download `Purchase_Prediction_Model.ipynb`.
2. Open it in Google Colab or Jupyter Notebook.
3. Install any required Python libraries.
4. Provide the dataset if prompted.
5. Run the notebook cells in order.

## Dataset
Online Shoppers Purchasing Intention dataset, available through the UCI Machine Learning Repository and Kaggle.
